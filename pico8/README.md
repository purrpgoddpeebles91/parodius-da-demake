# Parodius Da! Demake - PICO-8 cartridge source

This branch contains a PICO-8-style cartridge port built as a retro stylized source file and a browser-playable demo page.

Files:
- `pico8/index.html` - a web-playable PICO-8-inspired version
- `pico8/cartridge.lua` - the cartridge source code for a PICO-8 style implementation

This is a cartridge-inspired port for a classic 8-bit feel, not a compiled `.p8` binary or a real SNES ROM. It is intended as a lightweight retro target that matches the same gameplay structure in a classic cartridge form.
